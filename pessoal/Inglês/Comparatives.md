
Adjective
- Big → bigger or biggest


| Adverb                  | Register                           | Example                                                           |
| ----------------------- | ---------------------------------- | ----------------------------------------------------------------- |
| **Much**                | strong, neutral-to-formal          | This case is **much more complex** than the last one.             |
| **Far**                 | strong, neutral-to-formal          | The new process is **far simpler**.                               |
| **Slightly**            | mild                               | The fee is **slightly higher** this year.                         |
| **A bit**               | informal, mild                     | The deadline is **a bit tighter** this year.                      |
| **A little**            | informal, mild                     | The response was **a little slower** than expected.               |
| **A lot**               | informal, strong                   | Prices went up **a lot faster** than expected.                    |
| **A good/great deal**   | formal, strong                     | The revised draft is **a great deal clearer**.                    |
| **Even (for emphasis)** | adds emphasis/surprise, any degree | The second petition was **even more urgent**.                     |
| **Significantly**       | formal, precise                    | The waiting period was **significantly longer** than anticipated. |
| **Considerably**        | formal, precise                    | The costs were **considerably higher** than budgeted.             |
